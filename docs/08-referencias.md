# Referencias técnicas

Fuentes primarias utilizadas para contrastar las interfaces descritas. Los
resultados del caso provienen de las operaciones y comprobaciones privadas del
proyecto, no de estas páginas.

- [Nginx: configuración HTTP y directiva alias](https://nginx.org/en/docs/http/ngx_http_core_module.html).
- [Nginx: autenticación básica](https://nginx.org/en/docs/http/ngx_http_auth_basic_module.html).
- [PHP-FPM: configuración de procesos y pools](https://www.php.net/manual/en/install.fpm.configuration.php).
- [WP-CLI: search-replace y datos serializados](https://developer.wordpress.org/cli/commands/search-replace/).
- [Certbot: emisión, renovación y hooks](https://eff-certbot.readthedocs.io/en/stable/using.html).
- [Postfix: configuración básica](https://www.postfix.org/BASIC_CONFIGURATION_README.html).
- [Dovecot 2.3: usuarios con passwd-file](https://doc.dovecot.org/2.3/configuration_manual/authentication/passwd_file/).
- [GitHub: deploy keys y acceso por repositorio](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/managing-deploy-keys).
- [GitHub: claves oficiales de host SSH](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/githubs-ssh-key-fingerprints).
- [InterServer: política de DNS inverso](https://www.interserver.net/tips/reverse-dns-policies-at-interserver/).

Las políticas del proveedor, los requisitos de red y las versiones soportadas
pueden cambiar. El seguimiento de desbloqueo SMTP del caso tiene una fecha
específica y no debe interpretarse como una condición general garantizada para
otras cuentas de InterServer.
